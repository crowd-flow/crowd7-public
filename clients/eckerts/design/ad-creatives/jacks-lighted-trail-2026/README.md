## Why the flash-sale set looks different

The in-season set was built before the shipped-ad reference corpus existed and reads like a
website hero — full-bleed photo, small eyebrow, chip row. The flash-sale set is built to the
**actual Crowd7 house style** documented in `crowd7/marketing/fb-ad-reference-corpus/`
(Riamede, Colony Acres, Harbaugh, Jerry Smith, Amber Brooke, Baymo):

- **Giant display headline** carrying the offer, not the event name
- **Masked / arch-cropped photography** or a directional-scrim bleed — never a flat website hero
- **A hard-edged offer badge**: corner `% OFF` ribbon, struck-through regular price, huge sale price
- **A solid pill CTA**
- **A bottom rail** — sale dates · logo · terms · CTA
- **Sequenced across the sale window** (teaser → launch → scarcity → tier drop → 24hr → final hours),
  which is how every flash-sale set in the corpus is built

Palette and type stay JLT's own night sub-brand, so the ads match the ticket page they click through to.

See `flash-sale/README.md` for the full sale terms, the ten concepts, and the rules on what must
not be printed.
